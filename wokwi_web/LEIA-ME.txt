COMO RODAR NO WOKWI DO NAVEGADOR (sem instalar ESP-IDF)

1. Entre em wokwi.com com sua conta e crie um projeto novo:
   https://wokwi.com/projects/new/esp32-s3
2. Abra a aba "diagram.json", apague tudo e cole o conteúdo de diagram.json.
   O circuito aparece montado (ESP32-S3 + OLED + teclado 4x4 + RTC DS1307 + LEDs + buzzer).
3. Clique no editor de código, aperte F1 e escolha
   "Upload Firmware and Start Simulation..."
   Selecione o firmware.bin desta pasta.
4. A simulação começa. Abra o monitor serial para ver as linhas TX,...
5. Salve o projeto (Save) para ele ficar no seu perfil e você poder mostrar o link na apresentação.

Observações
- O código do sketch.ino do template é ignorado: o que roda é o firmware que você subiu.
- O Wi-Fi (Wokwi-GUEST) e o MQTT demoram alguns segundos. Se não conectarem,
  o OLED mostra "off" e a inferência continua normalmente (é 100% local).
- Teclas: 0-9 valor, # paga, A categoria, B +1h no relógio, * apaga, C limpa, D replay.
- Se mudar o modelo (rodar o notebook de novo), recompile o firmware com idf.py build e gere um novo .bin:
  esptool.py --chip esp32s3 merge_bin -o firmware.bin --flash_mode dio --flash_size 8MB @flash_args
  (rodar dentro de firmware/build) e copie o resultado para wokwi_web/firmware.bin.
